# Pawlet

Pawlet is a full-stack web application for dog adoption and pet shopping. It provides a secure platform where users can browse dog listings, purchase pet products, participate in community discussions, and read informative blogs.

## Features
- User Registration & Login
- Dog Marketplace
- Seller Shop Management
- Pet Product Store
- Shopping Cart & Checkout
- Community Forum
- Blog System
- AI Chatbot
- Admin Dashboard
- Seller Dashboard

## Technologies Used
- React.js
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Repository Contents
- `frontend/` – React frontend
- `backend/` – Express backend
- `Pawlet_Demo_Video.mp4` – Project demonstration video
